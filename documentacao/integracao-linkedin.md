## Onde o LinkedIn aparece no repositório

## Passo a passo no LinkedIn

### 1. Seção "Projetos"

1. No perfil, clique em **Adicionar seção do perfil → Recomendado → Adicionar projetos**.
2. Preencha:
   - **Nome do projeto:** `PortfolioHUB — Portfólio de projetos versionado com Git`
   - **Descrição:** use o [texto pronto](#descrição-do-projeto) abaixo.
   - **Competências:** Git, GitHub, GitHub Pages, HTML, CSS, JavaScript, Python.
   - **Período:** outubro de 2026 — atual.
   - **Associado a:** a instituição/bootcamp.
   - **Mídia → Adicionar link:** `https://marcellinhohm.github.io/PortfolioHUB/`
3. Repita para o projeto em destaque, **Bootcamp — Integração com a API do Claude**, com o link da pasta do projeto.

### 2. Seção "Em destaque" (Featured)

1. Clique em **Adicionar seção do perfil → Recomendado → Adicionar destaques → Adicionar um link**.
2. Cole `https://marcellinhohm.github.io/PortfolioHUB/`.
3. Título: `PortfolioHUB`; descrição: `Meus projetos acadêmicos e pessoais, organizados e versionados no GitHub.`

### 3. Informações de contato

1. Clique no lápis da introdução → **Informações de contato → Site**.
2. Adicione `https://github.com/MarcellinhoHM` com o tipo **Portfólio**.

### 4. Publicação

Faça um post anunciando o portfólio, usando o [texto do post](#post-de-divulgação), com o link do site. Depois, quando o vídeo estiver no YouTube, ele pode ser adicionado ao mesmo post ou à seção "Em destaque".
