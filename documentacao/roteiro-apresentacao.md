# Roteiro da Apresentação (5 minutos)

Roteiro do vídeo de apresentação do PortfolioHUB, acompanhando os [slides](https://marcellinhohm.github.io/PortfolioHUB/documentacao/slides/).

| Tempo | Slide | O que mostrar / falar |
|---|---|---|
| 0:00 – 0:30 | 1. Capa | Nome, objetivo do repositório: reunir projetos e montar um perfil profissional. |
| 0:30 – 1:00 | 2. Planejamento | Seções definidas: acadêmicos, pessoais, documentação e assets do site. |
| 1:00 – 1:45 | 3. Estrutura | Mostrar as pastas no GitHub e o README de cada uma. |
| 1:45 – 2:45 | 4. Versionamento | `git log --graph`, Conventional Commits, branches, Pull Requests #1 e #2, tags v1.0.0 e v1.1.0, Releases. |
| 2:45 – 3:30 | 5. Projeto em destaque | Abrir o projeto do bootcamp: README, notebooks e o que cada um ensina. |
| 3:30 – 4:15 | 6. GitHub Pages | Navegar pelo site: projetos, documentação, slides, versões e tema escuro. |
| 4:15 – 4:45 | 7. LinkedIn | Mostrar o projeto na seção Projetos/Em destaque do LinkedIn e os links do repositório. |
| 4:45 – 5:00 | 8. Encerramento | Próximos passos e links. |

## Dicas para gravar

- Deixe abertas, em abas: o site, o repositório, a aba de Pull Requests, a de Releases e o perfil do LinkedIn.
- Grave a tela em 1080p (OBS Studio ou a Ferramenta de Captura do Windows com `Win + Alt + R`).
- Publique no YouTube como **Não listado** ou **Público** e adicione o link no README e no LinkedIn.
