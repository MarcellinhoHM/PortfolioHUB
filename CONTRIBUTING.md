# Como contribuir

Obrigado pelo interesse no PortfolioHUB! Sugestões e correções são bem-vindas.

## Resumo

1. Abra uma [Issue](https://github.com/MarcellinhoHM/PortfolioHUB/issues/new/choose) descrevendo o problema ou a ideia.
2. Faça um *fork* do repositório e crie uma branch a partir da `main`:
   - `feature/<nome>` para novidades;
   - `fix/<nome>` para correções;
   - `docs/<nome>` para documentação.
3. Faça commits seguindo o [Conventional Commits](https://www.conventionalcommits.org/pt-br/) — ex.: `fix(site): corrige link do LinkedIn`.
4. Abra um Pull Request para a `main` preenchendo o modelo.

## Regras

- Não envie arquivos `.env`, chaves de API ou senhas.
- Mantenha o README do projeto alterado atualizado.
- Teste o site localmente antes de abrir o PR (`python -m http.server 8000`).

O passo a passo completo está no [Guia de Colaboração](documentacao/guia-colaboracao.md) e no [Guia de Git e Versionamento](documentacao/guia-git-e-versionamento.md).
