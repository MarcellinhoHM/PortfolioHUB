## Como adicionar um novo projeto pessoal

1. Crie uma branch: `git checkout -b feature/projeto-<nome>`.
2. Se o código ficar neste repositório, crie a pasta `projetos-pessoais/<nome>/` com um `README.md` seguindo o padrão:
   - objetivo do projeto;
   - tecnologias;
   - como executar;
   - estrutura de pastas;
   - prints ou link de demonstração.
3. Se o código ficar em outro repositório, adicione uma linha na tabela acima.
4. Adicione o card do projeto na seção **Projetos** do `index.html`.
5. Abra um Pull Request.
