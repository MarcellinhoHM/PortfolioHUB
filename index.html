Equipe e permissões

Contribuidores vêm da API do GitHub. Hoje o projeto tem um mantenedor (Admin); contribuições externas entram por fork e Pull Request. Toda mudança na main, inclusive do mantenedor, passa por Pull Request com os testes obrigatórios aprovados; ninguém faz push direto.
